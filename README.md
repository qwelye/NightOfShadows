# NightOfShadows
Стелс-хоррор от первого лица на Unity: зачистка заброшенного сектора от теневых сущностей

## Concept
Игрок с фонарём исследует тёмный сектор, проявляет
сущности лучом света и применяет протокол зачистки

## Core Loop
Экспедиция в заброшенный сектор в условиях ограниченной видимости --> Скан и идентификация аномальных теневых форм --> Фиксация сущности светом --> Ликвидация объекта путем ввода классификации в UI и активации протокола зачистки --> Эвакуация на базовую точку

## Core Mechanics
- Луч фонаря и конус взгляда (Vector3.Dot)
- Движение сущностей по NavMesh
- Коллективная агро-система
- Отступление, гашение фонаря, ложные двойники

## Challenges
* **Адаптивное отступление:** После нахождения, сущности избегают прямого света и отходят в неисследованные тёмные зоны
* **Саботаж освещения:** Враги способны гасить фонарь игрока, лишая его основного средства защиты и обзора
* **Фантомная оболочка:** Создание ложных объектов-двойников для дезориентации игрока и провокации ошибочного выбора в UI
